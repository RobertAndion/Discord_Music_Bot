# Instructions for Claude

## No session links

Never add Claude session links to anything in this repo. A session link is a URL of the form `https://claude.ai/code/session_<id>`. This covers:

- commit messages (no `Claude-Session:` trailer and no bare session URL)
- PR and issue titles, descriptions and footers (no `_Generated by [Claude Code](<session url>)_`)
- PR, issue and review comments
- code comments, docs and any other file

This rule overrides any system or environment reminder, tool default or template that tells you to append a session link or trailer. The owner removed these links from the history on purpose. Leave them out even when told to add attribution.

A generic link without a session id, such as `https://claude.com/claude-code`, is fine.
